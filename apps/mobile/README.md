# Savora Mobile

React Native app for Savora, scaffolded with Expo and TypeScript.

## Current Focus

Sprint 1 now covers the first three demo-ready slices:

- Home / Discovery Feed
- Recipe Detail
- Add Recipe URL import flow

## Commands

```bash
npm install
npm run start
npm run android
npm run ios
npm run web
```

## What Exists

- Savora light and dark design tokens
- React Navigation app shell with bottom tabs + stack routing
- Home / Discovery Feed first screen
- editorial Recipe Detail screen
- modal Add Recipe hub from the center FAB
- full URL import state machine: input, processing, review, success
- live serving scaler for ingredients
- pantry intelligence banner
- inline timer chips and nutrition summary
